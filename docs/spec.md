# videofabric — канонический стратегический документ

Статус: замысел проекта, заданный владельцем 2026-09-30 при создании репозитория. Решений по инструментам для конкретных выпусков ещё нет: инструмент на каждый выпуск согласуется с владельцем (указание 3 в `AGENTS.md`).
Дата: 2026-09-30.

Это единственный корень стратегической документации. Правила работы агентов — в `AGENTS.md`. Всё ниже — постановка владельца, приведённая без толкований агента; дословные слова владельца стоят в кавычках «».

## 1. Что делает фабрика

Владелец, 2026-09-30: «Фабрика создания видеоконтента с помощью агентов. Обзоры технических, технологических и околотехнических новинок и новостей. Приёмы обработки информации. Местами — аналитика с говорящей головой; её же можно ставить ведущей в обзоры. Живо, ярко, интересно.»

## 2. Форматы выпусков

«Ролики — отчасти на генерации, отчасти на точном отображении.»

- Длинные обучающие — «говорящая голова и графика».
- Новостные ролики — «несколько минут: основа — голова, фоновое разбавление — стоковые видео».

## 3. Инструменты, названные владельцем

Кандидаты; выбор на каждый выпуск согласуется с владельцем.

- HeyGen — «аватар. Возможно, им же и голос».
- HyperFrames — https://github.com/heygen-com/hyperframes
- Remotion с навыками video-shotcraft (https://github.com/Vincentwei1021/video-shotcraft) и video-talkcraft (https://github.com/Vincentwei1021/video-talkcraft).
- Blender — «в качестве одного из инструментов тоже (установить при необходимости, по согласованию со мной)». На этой машине не установлен (проверено 2026-09-30: нет `/Applications/Blender*`, нет команды `blender`).
- Генерация — «через API (Replicate, fal) или на своём сервере; 720p не обязательно — 480p и апскейл».
- Свой сервер с GPU — «попробовать»:
  - InfiniteTalk — https://github.com/MeiGen-AI/InfiniteTalk
  - Wan — https://github.com/Wan-Video/Wan2.1
  - апскейлер — «варианты: FlashVSR, SeedVR2»
  - SoulX-FlashTalk — https://huggingface.co/Soul-AILab/SoulX-FlashTalk-14B
  - AptAvatar — https://huggingface.co/TaoLiveAIGC/AptAvatar

## 4. Способ работы, заданный владельцем

«По возможности используем код, при необходимости — инструменты с прямым доступом или веб через мою подписку.» Работа ведётся через дочерних агентов на младших моделях; правила — в `AGENTS.md`.

Пока нет. Тематические рабочие документы агентов (разборы инструментов, результаты поисков, исследования) ведутся в `docs/knowledge/` по правилам `AGENTS.md`.
