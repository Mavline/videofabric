# Пост в вертикальный ролик кодом: сборщик `tools/post2video/render.py`

Что это: способ собрать короткий вертикальный ролик из текста поста без ручного монтажа.
Голос читает предложения поста, поверх клипов движутся крупные числа и фразы, снизу
субтитр текущего предложения, фоном музыка. Первый ролик: `films/anthropic-expectations-gap/`
(пост о различии ожиданий сотрудников Anthropic и американцев, 2026-10-20).

Происхождение: пилот начат в проекте grok-marketing 2026-10-20 по заданию владельца
(«Давай попробуем через код — попробуй сам»), в тот же день по его указанию перенесён сюда:
«объединить с существующим, только он называется videofabric». Переписка с владельцем и его
замечания к первой версии хранятся в архиве grok-marketing
(`docs/evidence/discussions/post-video-pipeline-2026/`).

## Что делает сборщик

- Берёт `scenario.json` ролика: для каждой сцены текст озвучки, крупный элемент (число,
  пара чисел с полосками или фраза), подпись, фон и пометка крупности плана.
- Синтезирует речь по сценам (xAI, `POST api.x.ai/v1/tts`, голос carina; запасные пути —
  модели Google и встроенный голос macOS `say`). Длительность сцены берётся из длины речи, ручной подгонки нет.
  Реплики кешируются в `.tmp/tts/`.
- Готовит фоновые клипы: обрезка в кадр 1080 на 1920, 30 кадров в секунду, одна
  цветокоррекция на все клипы (холодные тени, тёплые света, приглушённая насыщенность),
  при нехватке длины — замедление с интерполяцией кадров не более чем в 2,2 раза. Кеш в
  `.tmp/prep/`.
- Рисует поверх: число набегает от нуля, пара чисел с растущими полосками, фраза ложится по
  словам, субтитр текущего предложения, тонкая полоска хода, медленный рост шрифта. Затемнение
  тёмно-синее, акцент янтарный, шрифт Avenir Next из macOS.
- Сводит звук: музыка приглушается под голос компрессором с боковой цепью, плавное начало и
  конец, нормализация громкости на минус 16 LUFS.
- Инструменты: Python с Pillow, ffmpeg, `say`; новых зависимостей нет.

Запуск из корня репозитория:

```
python3 tools/post2video/render.py films/<ролик>/scenario.json films/<ролик>/exports/<имя>.mp4
python3 tools/post2video/render.py films/<ролик>/scenario.json --stills /tmp/stills   # по кадру на сцену
python3 tools/post2video/render.py --selftest
```

Ключи читаются из переменных окружения `XAI_API_KEY` и `GEMINI_API_KEY`, иначе из файла
`~/Projects/VoiceAgent/.env` (путь меняется параметром `--env-file`). Голос задаётся как
`--voice grok:carina`, `--voice gemini:Laomedeia` или именем голоса macOS.

## Устройство папки ролика

- `scenario.json` — сценарий (в git).
- `sources.md` — откуда каждый клип и трек, с лицензиями (в git).
- `assets/gen/`, `assets/stock/`, `assets/music/` — материалы (не в git, скачиваются по `sources.md`).
- `exports/` — готовые ролики (не в git). `.tmp/` — кеши (не в git).

## Правила монтажа, заданные владельцем 2026-10-20

Дословные замечания владельца к первой версии ролика (источник — переписка в архиве
grok-marketing, запись `owner-video-feedback-01`):

1. «Никогда не включать реверс ролика». Клип идёт вперёд один раз; сборщик не умеет
   ни реверса, ни зацикливания.
2. «Не повторять одну и ту же сцену и приём». Один клип на одну сцену, повтор клипа сборщик
   считает ошибкой и предупреждает.
3. «Используешь только наезд, или только отъезд, и максимум, 2 раза за ролик». Остальные
   кадры — неподвижная камера и движение внутри кадра.
4. «Каноны кино должны быть соблюдены — 3 дальности объектива — ближний, средний, дальний,
   сочетаемость цветов — комплиментарные по спектру». Крупность чередуется по сценам, палитра
   одна на ролик.
5. «Если надо натянуть время — возьми любые ролики со стока, хоть с природой, хоть с
   абстракциями». Кандидатов со стока скачивать с запасом и отбирать по контактным листам.
6. «Музыка хоть какая-то должна быть фоном».
7. Клип подбирается под смысл фразы: замечание владельца ко второй версии — сцена с комнатой
   стояла не под фразой «I'd like them in one room».

Предложение агента (не решение владельца): текст озвучки брать из поста, предложения можно
укорачивать, но не добавлять утверждений, которых нет в карте утверждений поста.

## Что известно о стоимости

- Голос xAI: `POST /v1/tts` с полями text, voice_id, language и output_format
  (объект codec и sample_rate) отдаёт WAV 24 кГц моно; цена за символ в этой сессии не
  проверялась, владелец назвал ключ оплаченным.

- Replicate, `bytedance/seedance-1-lite`, 480p, 5 секунд: 0,09 доллара за клип (страница
  предсказаний Replicate, 2026-10-20). На первый ролик семь клипов, 0,63 доллара.
- Сток и музыка Mixkit: бесплатно по лицензии Mixkit.
- Голос Gemini: 20 слов дали 244 аудиотокена (ответ API 2026-10-20); цена за токен не
  проверялась в этой сессии. Ключ из VoiceAgent для моделей синтеза речи работает на
  бесплатном уровне: десять запросов в сутки на модель (HTTP 429 после десятой реплики,
  2026-10-20). Сборщик переключается по цепочке моделей (`gemini-3.8-flash-tts`,
  `gemini-3.8-flash-lite-tts`, `gemini-3.1-flash-tts-preview`, `gemini-2.5-flash-preview-tts`)
  с тем же голосом и кеширует готовые реплики, поэтому пересборка квоту не тратит. Ролик на
  шестнадцать реплик за день с одной модели не собрать; включение оплаты для проекта ключа —
  решение владельца.
- Инструкции о манере чтения модель зачитывает вслух (проверено по длительности:
  20 слов без инструкции 9,7 с, с короткой 15,2 с, с длинной 24,4 с), поле системной
  инструкции отвергает. Текст передаётся без инструкций.

## Ключи и быстрый старт следующего ролика

Ключи лежат в `.env` в корне репозитория (в git не входит): `OPENAI_API_KEY` для памяти,
`REPLICATE_API_KEY` (владелец внёс 2026-10-20), `XAI_API_KEY` (скопирован из VoiceAgent по
указанию владельца 2026-10-20). Ключ Gemini остаётся только в `~/Projects/VoiceAgent/.env`; для
моделей речи он на бесплатном уровне. Сборщик ищет ключи в окружении, затем в `.env`
репозитория, затем в `.env` VoiceAgent.

Порядок для нового ролика:

1. Папка `films/<ролик>/` со `scenario.json` (образец — ролик anthropic-expectations-gap) и
   `sources.md`.
2. Текст озвучки из поста по предложениям, по сцене на ход мысли; крупный элемент и подпись.
3. Шот-лист по правилам выше: крупность, камера, смысл кадра. Сток Mixkit по прямым ссылкам
   с запасом, контактные листы, отбор. Генерация на Replicate (пока через веб-форму модели;
   запуск через API с ключом из `.env` ещё не написан) или на другом сервисе из `docs/spec.md`.
4. Музыка Mixkit в `assets/music/bed.mp3`.
5. Сборка: `python3 tools/post2video/render.py films/<ролик>/scenario.json films/<ролик>/exports/<имя>.mp4`,
   сначала с `--stills` для проверки кадров.

## Инструменты для будущих роликов (пожелания, перечень агента)

Владелец 2026-10-20: «Перечисли инструменты, в том числе JS для видео, они должны быть в
пожеланиях на будущие ролики». Перечень ниже — предложение агента; выбор инструмента на
каждый выпуск остаётся за владельцем (указание 3 в `AGENTS.md`), названные владельцем
инструменты перечислены в разделе 4 `docs/spec.md`.

Использовано в этом ролике:

- Python с Pillow: движущаяся типографика, числа, субтитры (шрифт Avenir Next из macOS).
- ffmpeg: подготовка клипов, замедление с интерполяцией кадров, цветокоррекция, сведение
  звука с приглушением, нормализация громкости, кодирование.
- Голос: xAI (`POST api.x.ai/v1/tts`, голоса carina, eve, ara, luna и другие); запасные — модели
  Google (бесплатный уровень, десять запросов в сутки на модель) и встроенный голос macOS `say`.
- Генерация клипов: Replicate, `bytedance/seedance-1-lite` (480p, 0,09 доллара за 5 секунд);
  дороже и лучше там же: `luma/ray-flash-2-540p` (0,033 доллара за секунду), `wan-video/wan-2.5-t2v-fast`
  (0,068 за секунду в 720p); цены со страниц моделей 2026-10-20.
- Сток: Mixkit (видео и музыка, бесплатная лицензия, прямые ссылки без ключа).
- Браузер через расширение Claude для Chrome: веб-формы сервисов, где нет ключа или API.

JS-инструменты для видео, которые стоит пробовать дальше:

- Remotion (React, кадр описывается кодом, рендер через headless Chrome) с навыками
  video-shotcraft и video-talkcraft — уже названы владельцем в `docs/spec.md`; подходит для
  графиков, схем, титров и сложной типографики, где Pillow тесен.
- HyperFrames от HeyGen — названа владельцем; связка с аватаром и голосом HeyGen.
- procedural-film — названа владельцем, опробована на burger-price-ai: рисованная анимация
  кодом (Node, Playwright-рендер собственных страниц).
- Motion Canvas (TypeScript): покадровая анимация схем и диаграмм с редактором времени.
- GSAP или анимация на canvas в собственной странице с захватом кадров headless-браузером:
  тот же путь, что у procedural-film, без его стиля.
- three.js: объёмные сцены и переходы кодом, если понадобится глубина без Blender.

Прочее:

- Blender (названа владельцем, не установлена) для объёмных вставок.
- fal.ai как вторая площадка генерации (названа владельцем).
- Распознавание речи с метками времени (whisper или его порт для Apple Silicon), если озвучка
  придёт готовой со стороны и под неё нужно класть картинку.
- Платные голоса (ElevenLabs и подобные), если голос xAI перестанет устраивать.
- Доступ к стоку по ключу (Pexels, Pixabay): больше выбор, чем у Mixkit, нужна бесплатная
  регистрация.

## Открытые вопросы

- Длина: первый ролик около двух с половиной минут; сокращение до полутора требует
  выбросить сцены из сценария, выбор за владельцем.
- Голос: по указанию владельца («возьми любой женский голос», затем «переключись на Грок, он
  оплачен тоже») взят xAI carina, голос из VoiceAgent; другие женские голоса xAI: ara, aurora,
  celeste, eve, iris, liora, luna (список `GET /v1/tts/voices`).
- Режим «готовая озвучка со стороны» (например, из NotebookLM) не сделан: нужны метки времени
  фраз, то есть распознавание речи.
